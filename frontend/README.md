# IncidentHub frontend

The IncidentHub frontend is a React JavaScript application built with Vite and Tailwind CSS.

## Requirements

- Node.js 20.19 or newer, or Node.js 22.12 or newer
- npm 11 or a compatible npm version

## Local setup

```bash
cp .env.example .env
npm ci
npm run dev
```

The development server runs at `http://localhost:3000` and stops with an error if that port is unavailable.

## Quality commands

```bash
npm run lint
npm test
npm run build
```
